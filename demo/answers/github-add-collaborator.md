# How do I add a collaborator to a GitHub repo?

1. Open your browser and go to https://github.com and sign in.

2. Click your profile photo (top-right) and select "Your repositories".  
   - Or go directly to the repository page URL (https://github.com/OWNER/REPOSITORY).

3. On the repository page, click the "Settings" tab near the top (right side of the repo tabs).

4. In the left sidebar, click "Manage access".  
   - If you do not see "Manage access", you likely do not have admin access to the repository or it's an organization repo where you need admin rights.

5. On the "Manage access" page, click the green "Invite a collaborator" button.

6. In the dialog that appears, type the GitHub username, full name, or email of the person you want to add. Select the correct user from the dropdown.

7. (Optional) Before sending, click the role dropdown and choose a permission level: "Read", "Triage", "Write", "Maintain", or "Admin" (the exact choices appear in the invite dialog).

8. Click the "Add NAME to this repository" or "Send invitation" button (the exact label may vary slightly) to send the invite.

9. The invitee must accept the invitation. They will receive a notification and can accept from their GitHub "Notifications" or the email invite.

Notes:
- You must be an admin of the repository to add collaborators. For organization repositories, you may need organization owner/admin privileges or to add a team instead: go to "Settings" → "Manage access" → "Invite teams or people".
- To remove a collaborator later: go to "Settings" → "Manage access", find the person, click the three-dot menu (or "Remove") and confirm removal.
