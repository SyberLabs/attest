# Where do I download Census population data for my county?

1) Open your web browser and go to: https://data.census.gov

2) Click the link labeled "Advanced Search" (top of the page).

3) Click "Geography".

4) In the geography chooser, click "County" (under the list of geography types).

5) Click the drop-down labeled "State" and select your state (for example, "California").

6) Click the drop-down labeled "County" and select your county (for example, "Los Angeles County").

7) Click the blue button labeled "Update Search" (or "Done" if shown) to apply the geography.

8) Back in Advanced Search, click "Surveys".

9) Select the survey you want:
   - For current multi-year estimates choose "ACS 5-Year Estimates".
   - For the official population count from the 2020 Census choose "Decennial Census".

10) Click "Topics".

11) In Topics, type and select "B01003: Total population" (or type "population" and choose the topic/table labeled "Total Population" or "B01003: Total Population").

12) Click the blue button labeled "Search" (top-right).

13) In the search results, click the table titled "B01003: TOTAL POPULATION" (or the specific table name that appears for the selected survey).

14) On the table page, confirm the geography in the header shows your county.

15) Click the button labeled "Download" (usually at the upper-right of the table).

16) In the Download dialog, choose format "CSV" (or "CSV / Excel") and click the blue button labeled "Download" (or "Download Data").

17) Save the CSV file when prompted — it will contain the population for the selected county.

Notes:
- If you need yearly estimates for multiple years, in Advanced Search use "Year" to pick a specific ACS year before searching.
- If you want a quick single value without table details, search the data.census.gov search box (top) for "County Name population" and open the relevant result, then use "Download".
