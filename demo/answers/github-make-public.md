# How do I make a GitHub repository public?

1. Open your web browser and go to https://github.com.  
2. If you aren’t signed in, click the "Sign in" link (top-right) and sign in with your account.  
3. Click your profile photo (top-right) and select "Your repositories", or go to the repository by URL (https://github.com/OWNER/REPOSITORY).  
4. On the repository page, click the "Settings" tab.  
5. Scroll down to the "Danger Zone" section at the bottom of the Settings page.  
6. Click the "Change visibility" button next to "Change repository visibility".  
7. In the dialog that appears, click the "Make public" option (if shown), then click the "I understand, change repository visibility" button.  
8. When prompted, type the repository name exactly as shown to confirm, then click the final "I understand, change repository visibility" button.

Notes:
- You must have admin permissions on the repository to change its visibility.  
- If the repository belongs to an organization, org members or policies may require additional approvals; you might see a "Request to make public" flow instead.  
- Changing a repository to public makes its code, issues, pull requests, and history visible to everyone.
