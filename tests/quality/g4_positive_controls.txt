# file, or a missing, skipped, xfailed or xpassed id, fails the gate, as does an
# empty section. Parametrized mutants are listed one by one. A pass covers these
# ids only. It is not a coverage figure.

# twin:    the same fixture with one input changed must be refused.

#          control fail. This is what catches a "refuse everything" false green.
